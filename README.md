# R36S ROMS STORE · Atualizações

Baixe o **instalador ZIP** na [última versão](https://github.com/JammesPark/R36S-ROMS-HUB-STORE-UPDATES/releases/latest). Extraia o pacote sem o sufixo OTA na pasta ports do cartão. A partir da 0.6.7-beta, a loja verifica novas versões ao abrir com Wi-Fi. Escolha **Atualizar agora** para iniciar o download e confirme a instalação depois da verificação.

O feed do aplicativo está em `ota/update.json`. O GitHub Actions confere o manifesto e baixa os dois ZIPs publicados para verificar a integridade antes de liberar a atualização aos consoles.

Base R36S PORT HUB por Lag do Lira, sob GPL-3.0. O instalador inclui os avisos de licença dos componentes.

# Contributors — R36S ROM HUB STORE

Este documento registra retroativamente as contribuições ao projeto desde o início de seu desenvolvimento e estabelece a forma de reconhecimento das contribuições futuras.

## JammesPark (James Park)

[Perfil no GitHub](https://github.com/JammesPark)

Criador e responsável pelo projeto R36S ROM HUB STORE, definição de requisitos, direção visual, decisões de desenvolvimento e publicação, organização do acervo e testes no console.

## ChatGPT (OpenAI)

[ChatGPT](https://chatgpt.com/)

Colaboração no desenvolvimento assistido por inteligência artificial, em conjunto com JammesPark, desde o início do projeto. As contribuições abrangem:

- Desenvolvimento e revisão de código Lua/LÖVE e ferramentas auxiliares.
- Interface, protótipos e adaptação dos temas Pulse Edition e Matrix Edition.
- Diagnóstico de falhas, correções, testes e compatibilidade de tela.
- Catálogo de ROMs, associação de capas, validação de dados e integração com o armazenamento Cloudflare R2.
- Automação com GitHub Actions, empacotamento, canais de atualização OTA e entregas experimentais.
- Documentação, planejamento e manutenção.

JammesPark orienta, aprova e testa as alterações; ChatGPT auxilia na implementação e análise. Este reconhecimento abrange as contribuições anteriores nos repositórios de código e de atualizações, inclusive no catálogo e nas versões experimentais, sem reatribuir individualmente commits cuja participação não tenha sido verificada.

## Registro de contribuições futuras

Para alterações realizadas com a assistência do ChatGPT, acrescentar ao final da mensagem do commit:

```text
Assisted-by: ChatGPT (OpenAI)
```

A atribuição descreve assistência de IA, não uma conta pessoal de GitHub, vínculo oficial com a OpenAI ou autoria exclusiva. Este documento não altera a titularidade de direitos, a licença GPL-3.0 do projeto, os commits anteriores, as tags ou os pacotes publicados.

A lista nativa Contributors do GitHub é calculada pela plataforma; este registro documental é independente dela.
